# Correction wave 2 proposal

This folder records the proposed corrections to the 14 contradicted fields imported in Cite wave 2. The graph, rules, schema and provenance have not been changed. `drafts.json` and `review.md` are the approval record; the Cite wave 2 finder prompts, page text, judge prompts and responses remain in `../cite-02/judge/`.

The proposer inspected current official guidance and copied wording elsewhere in each affected node. A separate judge session must check every accepted new value after it is applied. Two Cite wave 2 contradictions, the LPA death notification and the England and Wales death registration scope, appear to reflect the judge reading a broader service page than the node describes; their proposed text clarifies the node's scope.
